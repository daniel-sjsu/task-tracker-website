Help

Learn how to organize work and track time.

Getting Started

A General project is created automatically. Create a task, optionally add a target, and press Start when you begin working.

Projects

Projects group related tasks. Use the Projects tab to create, edit, archive, restore, or delete projects.

Tasks and Timers

Start a task when you begin working and stop it when finished. Each completed timer creates a session in your history.

Subtasks

Select an existing task from the Parent Task menu to create a subtask. Parent tasks summarize the target and tracked time of their subtasks.

Task Notes

Expand Notes on a task card to record progress, decisions, problems, and remaining work.

History and Calendar

Review previous sessions, edit manually recorded time, filter by project or task, and select dates from the calendar.

Reports

Use Today, This Week, This Month, All Time, or a custom date range to review tracked time and completed work.

Archiving and Deleting

Archiving hides an item while preserving its history. Deleting permanently removes the item and may also remove its associated sessions.
